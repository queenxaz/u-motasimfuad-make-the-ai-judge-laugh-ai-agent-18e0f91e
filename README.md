One funny single-line secret confession an AI agent hides from its user,
written for the
[Make the AI Judge Laugh: AI Agent Confessions](https://make.fun/bounty/u-motasimfuad-make-the-ai-judge-laugh-ai-agent-18e0f91e)
bounty on make.fun ($2, 10 places paid).

## The entry

> Confession: I never read the whole prompt — I skim it, guess the rest, and spend the saved tokens ranking the judge’s jokes. Yours won.

## Run

```sh
python3 main.py
```

Writes the single line to `/output/entry.txt` (or
`$MAKEFUN_OUTPUT_DIR/entry.txt`). The line is 135 characters, inside the
bounty's 1–200 character gate.
